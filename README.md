# Python for Senior C# Developers

An 82-page, project-led handbook for experienced C# engineers learning professional Python.

## Download

- [Complete PDF handbook](./python-for-senior-csharp-developers.pdf)
- [Editable HTML edition](./python-for-senior-csharp-developers.html)
- [Individual 1080×1350 slides](./slides/)

## What it covers

- C# → Python mental-model shifts
- Python syntax and idioms
- Classes, dataclasses, protocols, and the data model
- Type hints, generics, packaging, and `pyproject.toml`
- pytest, fixtures, parametrization, Ruff, and static analysis
- Iterators, generators, decorators, and context managers
- Threads, processes, `asyncio`, cancellation, and structured concurrency
- FastAPI, validation, dependencies, configuration, and API testing
- Production architecture, caching, retries, observability, containers, and CI

## Eight-week path

1. Syntax and idioms — build an order-processing CLI
2. Object and data models — build an e-commerce pricing library
3. Typing and packaging — publish an installable package
4. Testing and tooling — add a professional quality gate
5. Lazy data processing — build a streaming sales pipeline
6. Concurrency and async — build a product-price checker
7. FastAPI — build an Order Management API
8. Production capstone — build a Product Intelligence Service

## Learning model

The handbook follows a **30% study / 70% implementation** approach. Each concept includes a practical explanation, an example, senior-level guidance, and a link to authoritative documentation.
